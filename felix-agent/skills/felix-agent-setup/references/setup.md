# Initial setup

The source of truth is the [starter README](https://github.com/frdteknikelektro/felix-agent-starter) and its Compose file. Check Git, `docker compose version`, and Docker daemon availability; if missing, explain the prerequisite. Clone the starter into the standard path only when it does not exist, create `workspace`, and pull the setup image as upstream documents. Do not replace existing files.

Prefer the browser Setup Console. Its one-time authenticated URL is a secret: never read, emit, or paste it into chat or agent tool output. Have the user run setup in their own terminal and open the authenticated URL printed there, replacing the internal port with the loopback host port if required by the [Setup Console documentation](https://github.com/frdteknikelektro/felix-agent/blob/main/docs/setup-console.md). On macOS/Linux/WSL use `env UID="$(id -u)" GID="$(id -g)" docker compose --profile setup run --rm --service-ports setup-ui`; on Windows Docker Desktop omit `env UID=... GID=...`. Keep that process alive. From another terminal discover the one-off container and its mapped loopback port, using `docker compose ps --all` and Docker port inspection if `docker compose port setup-ui 53317` does not identify the `run` container. Give the user the mapped port only; let them combine it with the private URL. Never bind it to a public interface. If browser setup cannot be used, offer the upstream interactive terminal setup, not a fabricated headless configuration.

The user configures at least one harness and message source and enters secrets in Setup. Do not read or display `.env` to determine progress. Ask the user to finish Setup and save their Owner password; wait for them to confirm setup is complete, then stop the setup process and follow upstream's `docker compose up -d --wait`. Discover the Owner Console port using `docker compose port felix 3000`, check its loopback `/healthz`, and report the console URL. The user supplies the Owner Console secret locally. Health is not evidence that a specific provider or channel works; verify only what was requested and actually exercised.
