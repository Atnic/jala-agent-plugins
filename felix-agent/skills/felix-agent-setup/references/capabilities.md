# Connections and Felix skills

Use the Owner Console and the documentation corresponding to the installed image. Discover enabled channels, harnesses and available skills without exposing credentials. Help the user configure or troubleshoot requested connections using documented Felix interfaces; the user performs sign-in and enters secrets locally. Verify the specific connection only when a supported non-destructive check is available.

The API channel's API-key identity is a contact, not the owner. It cannot be assumed to have owner permissions or approve its own protected actions. For owner-only work use the Owner Console when supported; otherwise report the limitation. See [API sessions](https://github.com/frdteknikelektro/felix-agent/blob/main/docs/agents/api-sessions.md) and [API keys](https://github.com/frdteknikelektro/felix-agent/blob/main/docs/agents/felix-api-keys.md), verifying that they match the installed release. Some releases document API sessions and turns; their existence does not grant owner authority. Do not promise A2A or introduce task delegation as part of this plugin.

Inspect built-in skills but do not edit them: they cannot be changed. For creating or updating custom Felix skills, follow the [custom skills repository](https://github.com/frdteknikelektro/felix-agent-custom-skills) and installed-release instructions, including required metadata and dependencies. Make changes only to custom skills; use supported registration and reload procedures and verify the resulting skill appears. Do not import Codex or Claude Code skills. If an operation lacks a verified interface, explain its limitation and offer a documented manual path.
