Read and apply the bundled [grilling](../grilling/SKILL.md) and [domain-modeling](../domain-modeling/SKILL.md) skills together. Use grilling to run the interview. Use domain modeling to check the project's documents and capture agreed terms and decisions as the interview proceeds.

Recording an agreement is part of the interview. Wait for the user to confirm the shared understanding before carrying out the plan.
