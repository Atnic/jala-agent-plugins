# Branding

Use supplied or verified official artwork; record its origin in the plugin README. Inspect the source before selecting it. Prefer original SVGs or sufficiently large PNGs over enlarged favicons.

For plugin display, preserve the artwork's proportions on a square canvas with padding. Keep originals separately if adding a display wrapper. Use transparency where appropriate and add a dark variant when contrast requires it and the host supports it. Set manifest paths relative to the package root.

Render light and dark previews at typical icon sizes and a larger inspection size when tools are available. Check clipping, centering, legibility, and contrast. Report missing render checks rather than claiming the host display was tested. A square viewBox alone does not prove a good display result.

Without suitable artwork, omit optional icon fields. Asset creation does not imply permission to install or publish the plugin.
